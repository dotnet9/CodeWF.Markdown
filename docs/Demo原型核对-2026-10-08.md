# Demo 原型与实现核对（2026-10-08）

对照本仓库 `design/prototype.html` 的当前 HTML/CSS，修复 Demo 和实时编辑控件。以现行原型为准，旧计划中的 48px 标题栏、200px 侧栏等数值已过时。联调版本：`14.0.1-dev.20261008.9`。

## 方法

阅读原型 CSS/结构，核对 XAML、控件模板、实际布局/画刷；加载原本的 App/MainWindow，用 Avalonia.Headless + Skia 离屏截图。明暗主题分别运行 1400×900、980×640 的编辑、分栏、实时、预览，并滚到正文中部/底部。输入仅发到离屏窗口，不操作真实键鼠。

原型浏览器访问被环境拒绝，本轮没有浏览器原型截图，也没有全页面逐像素相似度结论。

## 验证结果

- **182 项 Release 测试通过**：源码跨度、CRLF/空白保留、嵌套/有序列表、引用链接、表格结构、主题隔离、Mermaid 深色继承和共享引用导航等。
- 实际离屏鼠标点击标题后焦点保留在 TextBox；Ctrl+A/输入只改活动标题，Esc 恢复渲染，切回分栏后源码包含修改。
- 实际点击共享引用中的段落，输入后保留兄弟段落锚点链接和后续任务列表。
- 八份样例解析/写回严格相等；四模式切换不改变原文。性能插入/停止与双预览入口通过。
- 同时存在的浅/深编辑器语法定义独立；URL 颜色与 LinkKey 一致。

PNG/日志在 `artifacts/ui-verification/`，不纳入 Git。首屏 `demo-Light-1400-split.png`、`demo-Dark-1400-live.png`；编辑证据 `demo-live-editing.png`、`demo-live-edited.png`、`demo-live-quote-edited.png`；局部 `*-header.png`。

复现见 Vex 的 `scripts/ui-verification/README.md`。常规检查：

```powershell
dotnet build CodeWF.Markdown.slnx -c Release
dotnet test tests/CodeWF.Markdown.Tests/CodeWF.Markdown.Tests.csproj -c Release
```

## 剩余差异

1. 源码 CSS 行距 1.7，对应约 22.1px；AvaloniaEdit 当前实测 17.525px，DefaultLineHeight 只读。没有为行距放大字体，本轮尚未对齐。
2. 原生滚动条和字体度量仍与网页不同；Windows 窗控、拖动/最大化、多 DPI 未通过离屏验证。
3. 嵌套/混合引用仍按编辑块显示；更改列表/引用成员会规范化该组 Markdown，未改动组保留原文。尚未实现完整 Typora 式行内编辑。
4. IME 连续组字、复杂嵌套续行、远程图片失败重试和所有导出格式未穷尽实测。
5. 四包仅本地打包联调，未发布 NuGet/标签；其他机器需先打包。下一轮优先源码行距和原生窗口/DPI，再做正式发布检查。
